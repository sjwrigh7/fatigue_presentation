Sensor Optimization Methodology

Digital engineering approach

  • Does not rely on existing experimental data
  • Only requires initial computer models of combustion and piston heat transfer
  • Utilizes statistical approaches with synthetic data generated by the computer models

Sensor Optimization Methodology

One-at-a-time strategy

  • Optimizes each sensor to a specific unknown calibration parameter (e.g., backside HTC)
  • Reduces computational expense
  • Avoids multiple optimums associated with Fisher information D-optimality strategies

Sensor Optimization Methodology

Optimization Criterion

Fisher information
\[ \begin{aligned} O & = \mathcal{I}_{1,1} \\ \mathcal{I}_{1,1} & = \frac{-\partial^2 \log L}{{\partial \theta}^2} \\ \end{aligned} \]

First stage optimization

  • Initialize an array of parameter settings
  • Genetic algorithm optimization for each sensor at each parameter setting
    • Genetic algorithm efficiently explores the space
    • Proposed measurment locations are mapped to the closest FEM node to constrain the search to the piston geometry
  • This gives an array of apprximate optimums

Second stage optimization

evaluation region definition

  • Solve for minimum and maximum values of $x$ and $y$ from coordinates in solution popluations
  • Define template region as Cartesian product $R= [x_{\textrm{min}},x_{\textrm{max}}] \times [y_{\textrm{min}},y_{\textrm{max}}]$
  • Map this to the discrete set of all FE nodes within the region

Second stage optimization

  1. Evaluate bounding region via array of approximate optimums
  2. Direct evaluation of Fisher information at all parameter settings inside region
  3. Find best worst-case scenario (minimax optimization)

Two-stage optimization example

Introduction

  • Consider we are trying to optimize a sensor to the top segment of the cooling gallery
  • We will refer to this as $\theta_1$
  • There are 7 other $\theta$s in our model: $\boldsymbol{\theta}=(\theta_1,\ldots,\theta_8)$

Two-stage optimization example

  • Generate a 25x8 Latin hypercube design
  • 25 configurations of our 8 $\theta$, denote this as $\boldsymbol{\Theta}^*$
  • Consider each of these 25 configurations a different possibility of the "true" values of our unknown BCs
    • Both for the BC of interest, $\theta_1$, and the other BCs that are held fixed

Two-stage optimization example

Data synthesis

  • Solve the FE model at each configuration
  • Draw 200 samples of Gaussian noise and add this to the FE model results
  • This gives us synthetic temperature data at each of the 25 configurations of "truth"

Two-stage optimization example

Surrogate Models

  • For each configuration of "truth" in $\boldsymbol{\Theta}^*$, evaluate a grid of values for $\theta_1$
  • This gives us data to train a surrogate model for temperature as a function of $\theta_1$ at each configuration of "truth"

Two-stage optimization example

First stage genetic algorithm

  • Use a genetic algorithm to maximize Fisher information for each of the configurations in $\boldsymbol{\Theta}^*$
  • This gives us populations of approximate solutions for the best sensor location to calibrate the top segment of the cooling gallery
  • Each population is a set of approximate optimums based on the values of each $\theta$ from the Latin hypercube

Two-stage optimization example

Second stage robust optimization

  • Calculate the boundary around all of the solution populations via $R=[x_{\textrm{min}},x_{\textrm{max}}] \times [y_{\textrm{min}},y_{\textrm{max}}]$
  • Map this to the FE mesh to find all nodes inside the boundary, $R'$
  • Calcualte the Fisher information for each location in $R'$ using the synthetic data for every configuration in $\boldsymbol{\theta}^*$

Two-stage optimization example

Second stage robust optimization

  • For each location in $R'$, we find the minimum Fisher information, minimized over the different configurations of $\boldsymbol{\Theta}^*$, denoted as $\mathcal{I}_{\textrm{min}}$
  • We find the location that has the greatest $\mathcal{I}_{\textrm{min}}$
  • This location is the "safest" choice for placing a sensor

Conclusions

Posterior variance

  • Reduced posterior variance when calibrating to the algorithm-selected locations in 99% of parameter configurations
  • Average reduction in posterior variance of 70.4%
    • Average standard deviation decrease in estimates of unknown boundary conditions \[76 \space Wm^{-2}K^{-1}\]
